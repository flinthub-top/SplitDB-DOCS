## 关于 SplitDB
SplitDB 是基于 SQLite 的分片存储引擎，面向低资源私有化社区设计。本仓库用于存放相关架构方案与说明文档。

SplitDB is a lightweight, sharded SQLite storage engine designed for low-resource community platforms.
For detailed architecture, please refer to the Chinese Whitepaper.
